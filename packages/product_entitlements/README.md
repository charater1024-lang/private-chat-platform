# product_entitlements

This package defines a closed, fail-closed commercial feature policy. It does
not validate purchases and accepts a `CommercialPlan` only after the app has
verified a signed claim.

Security and user-control features are always available:

- true E2EE, OS-protected device keys, device verification and key transparency
- session inventory/revocation and authentic security updates
- encrypted export/import, content deletion, blocking and reporting

Ordinary direct/group messaging, replies, reactions, receipts, local search,
media, reliable retry, accessibility and Korean/English UI are also available
on the community plan. Collaborative document creation/editing is a Team work
feature. A downgrade may make existing documents read-only, but encrypted
export, deletion and security history remain always available. Only
organization workflows and managed services are commercially gated.

The package makes no claim that a listed feature has been fully implemented.
It controls commercial eligibility only; release-readiness remains governed by
the repository's security and native release gates.
